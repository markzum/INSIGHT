# Шлюз ИНСАЙТ

Фронтенд запрашивает `GET /workspace` и `POST /insights/{id}/questions`. Агент отвечает своими инсайтами и чатом. Шлюз переводит одно в другое и не вызывает модель сам.

Отдельная команда собирает ленту: парсер → дедупликация → JSONL, который читает агент.

## Запуск всего стека

Из корня репозитория:

```bash
docker compose up --build
```

- фронтенд: `http://127.0.0.1:4173`
- шлюз: `http://127.0.0.1:8080`
- агент: `http://127.0.0.1:8010`
- дедупликация: `http://127.0.0.1:8001`
- парсер: `http://127.0.0.1:8002`

Перед агентом одноразовый шаг забирает офлайн-ленту парсера, кладёт её в дедупликацию и записывает кластеры в общий файл. Если этот шаг не собрал ни одного кластера, в файл попадает короткая синтетическая лента со ставкой и курсом юаня. Агент в compose работает с `MOCK_LLM=1`, без ключа.

Фронтенд в этом запуске получает адрес шлюза через `ALFA_API_BASE`. Без этой переменной он открывает локальное демо.

Локально без Docker поднимите агент, затем из `gateway/`:

```powershell
$env:AGENT_URL = "http://127.0.0.1:8000"
.venv\Scripts\python -m uvicorn gateway.api:app --port 8080
```

Сервер фронтенда из каталога `frontend/`:

```powershell
$env:ALFA_API_BASE = "http://127.0.0.1:8080"
node scripts/serve.cjs
```

Период ленты по умолчанию `2026-09-01` … `2026-10-31`: в него попадают и пример кейса про ставку 11 сентября, и более поздние материалы. Роли фронтенда сопоставляются так: финансовый директор → `cfo`, генеральный директор → `ceo`, казначей → `treasurer`. Если порт 8000 занят системой, агент запускают на 8010 и этот адрес пишут в `AGENT_URL`.
