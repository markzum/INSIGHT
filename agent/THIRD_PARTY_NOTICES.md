# Сторонние компоненты

Ключи и выгрузки кейса в репозиторий модуля не входят. CSV и PDF монтируются снаружи.

## Модели

Используются только модели из списка кейса, и только если их имена переданы в окружении. Других имён в коде нет.

- Gemma 4 26B A4B — простые задачи, сюда ставится `LLM_MODEL_LIGHT`, если так решила команда
- GLM-5.3-Flash — сложный анализ, типичное значение `LLM_MODEL_REASONING`
- Qwen3.6 35B A3B — универсальная, может стоять в `LLM_MODEL_DEFAULT`
- DeepSeek-V4.1-Flash — длинный текст и связи, подключается тем же способом через env, отдельного вызова в коде нет
- Qwen3-VL-30B-A3B-Instruct — изображения, модуль её не вызывает: PDF кейса не распознаются зрительной моделью
- Kimi-K2.6 — обработка текста, тоже только если имя передано в env

Доступ — OpenAI-совместимый HTTP организаторов (`LLM_BASE_URL`). Это смоделированная интеграция: своего аккаунта провайдера в модуле нет.

## Библиотеки

- Python 3.12
- fastapi, uvicorn — HTTP
- pydantic — модели запроса и инсайта
- jsonschema — проверка ответа модели и аргументов инструментов
- httpx — клиент к LLM
- pyyaml — справочники отраслей, чувствительности, документов и макропоказателей
- pypdf — чтение текстового слоя PDF
- rank-bm25 — поиск по фрагментам аналитики
- pandas — загрузка CSV
- pytest — тесты, в основной образ не ставится

Агентные фреймворки и внешние AI-сервисы, кроме разрешённого LLM-эндпоинта, не подключаются.

## Данные

- Обезличенные CSV кейса (`df_Uid_data_hack.csv`, `df_Fid_Uid_link_hack.csv`, `df_Uid_payment_hack.csv`) — читаются по пути из env, в git модуля не копируются
- PDF Центра макроэкономических исследований — тот же режим. У поставки нет текстового слоя
- `agent/data/synthetic/` — вымышленные клиенты, платежи, кластеры и короткие фрагменты для тестов

## Смоделированные интеграции

- `dedup/` пишет JSONL кластеров. Агент читает его через `AGENT_NEWS_PATH`; если путь пуст, берётся синтетика
- `frontend/` забирает инсайт и trace по схемам в `schemas/`
