# Сторонние компоненты и происхождение материалов

Ниже описан автономный фронтенд и его учебный набор `data/demo.json`. В общем запуске из корня репозитория фронтенд получает компании и разборы от шлюза; состав всего решения — в корневом `THIRD_PARTY_NOTICES.md`.

## Код и среда

Фронтенд написан на JavaScript, HTML и CSS; внешних исполняемых библиотек, CDN и пакетов приложения нет. Сборка, локальный сервер и тесты используют стандартные модули Node.js. Node.js распространяется на условиях MIT с отдельными уведомлениями для включенных компонентов: https://github.com/nodejs/node/blob/main/LICENSE. Node.js не поставляется внутри этого проекта.

Используются системные шрифты браузера и операционной системы. Файлы коммерческих шрифтов не включены.

## Материалы кейса и исходный прототип

- Требования: предоставленный пользователем документ «Альфа Хак_Новостная аналитика.pdf». Права на исходный документ принадлежат его правообладателям; локальная копия находится в `references/` вместе с исходным JSON и материалами аудита. Сервер не публикует эту папку.
- Отправная точка: предоставленный пользователем проект `alfa-insights-prototype` и вручную подготовленный `news_card_demo.json`. Их наличие не считается подтверждением реальной интеграции с банком.
- Названия «Альфа-Банк» и «Альфа-Бизнес» используются для обозначения контекста учебного кейса. Это не утверждение об одобрении, партнерстве или принадлежности интерфейса банку.

## Синтетические данные

Компании, их названия и признаки, события, источники, цитаты, численные оценки релевантности, сценарии, риски, возможности и ответы в `data/demo.json` являются вымышленными тестовыми материалами. Они не описывают реальных клиентов, реальные новости или реальные рекомендации банка. Совпадения с реальными организациями случайны.

Статус факта `demo_only` означает соответствие тексту демонстрационного источника, а не внешнюю проверку события. AI-интерпретации имеют статус `prewritten_demo`: это заранее подготовленный пример ожидаемого представления результата, а не ответ модели. Аналитика Альфа-Банка не загружена; поле банковской позиции оставлено пустым с явным статусом `not_loaded`.

## Смоделированные и отсутствующие интеграции

| Компонент | Состояние в этом комплекте |
| --- | --- |
| Профиль компании и роль | Выбор из синтетического fixture и локальные предпочтения |
| Новости и источники | Локальные вымышленные записи, без работающего парсера |
| Аналитика Альфа-Банка | Не загружена, экспертная позиция не имитируется |
| Ранжирование | Клиентская демонстрационная логика на заранее заданных данных |
| Этапы агента и проверки | Демонстрационное представление подготовленных этапов |
| Уточняющие вопросы | Заранее подготовленные ответы; генерации LLM нет |
| Закладки, действия, обратная связь | Локальное состояние браузера, без отправки банку |
| Авторизация, RAG, инструменты агента, LLM | Не реализованы |
| API рабочего пространства и вопросов | Точки подключения и контракт; сервер не поставляется |

В прототип не включены модели, веса моделей, внешние AI-сервисы, платные API, производственные ключи или реальные клиентские данные. Для будущей серверной реализации требуется использовать только модели и способ построения агентной логики, разрешенные приложением 3 кейса.
