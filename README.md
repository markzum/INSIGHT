# ИНСАЙТ

Сервис для руководителя крупного бизнеса в Альфа-Бизнесе. Он собирает внешние новости и аналитику Альфа-Банка, отбирает события под конкретную компанию и объясняет, что произошло, почему это важно именно ей, какие есть риски и возможности, что по этому поводу написал банк и какой следующий шаг стоит проверить.

Интерфейс называется «Бизнес-пульс». Факты, позиция банка и интерпретация показаны отдельно. Утверждения в разборе ссылаются на источник.

## Архитектура

Модули не импортируют друг друга. Между ними HTTP и файл JSONL.

```text
парсер :8002  →  дедупликация :8001  →  clusters.jsonl
                                              ↓
фронтенд :4173  →  шлюз :8080  →  агент :8010
```

- `parser/` читает RSS разрешённых изданий и локальные материалы банка, классифицирует текст и выделяет факты. По умолчанию работает офлайн на фикстурах и в сеть не ходит.
- `dedup/` склеивает точные и близкие перепечатки классическими методами: канонический URL, хеш текста, MinHash и Jaccard, косинус заголовков. Банковская аналитика не смешивается с внешней новостью. LLM и эмбеддингов нет.
- `agent/` считает профиль клиента, ранжирует кластеры и проходит цикл план → инструменты → черновик → проверка → правка. Инструменты только из белого списка. Новости и цитаты банка модель видит как недоверенные данные. Цикл, реестр и проверка написаны здесь, без LangChain, LangGraph, CrewAI и AutoGen.
- `gateway/` переводит инсайт агента в рабочее пространство фронтенда и не вызывает модель.
- `frontend/` проводит сценарий от выбора компании и роли до разбора, источников и уточняющего вопроса.

Агент один. Роли финансового директора, генерального директора и казначея меняют видимые признаки и подсказки по продуктам, а не отдельную модель.

## Окружение

- Docker Compose, либо Python 3.12 и Node.js 22
- Для полного кейса в корне репозитория, до `docker compose up`: `df_Uid_data_hack.csv`, `df_Uid_payment_hack.csv`, `df_Fid_Uid_link_hack.csv` и PDF аналитики банка. Одноимённый `.txt` рядом с PDF используется, если у PDF нет текстового слоя
- Эти файлы в git не входят. Без них стек поднимается на синтетических клиентах `C_LOAN`, `C_DEPOSIT`, `C_IMPORT`, `C_DOMESTIC`, `C_SUPPLIER`, `C_GROUPMATE`, `C_SPARSE` и коротких фрагментах банка

Версии зависимостей зафиксированы: `agent/uv.lock` и `agent/requirements.lock`, `parser/requirements.lock`, `dedup/requirements.lock`, `gateway/requirements.lock`. У фронтенда нет npm-зависимостей, версия Node — `frontend/.node-version`.

## Запуск

Из корня:

```bash
docker compose up --build
```

- фронтенд: http://127.0.0.1:4173
- шлюз: http://127.0.0.1:8080
- агент: http://127.0.0.1:8010
- дедупликация: http://127.0.0.1:8001
- парсер: http://127.0.0.1:8002

Перед агентом одноразовый шаг забирает ленту парсера, прогоняет дедупликацию и записывает кластеры в общий файл. Если кластеров нет, в файл попадает синтетическая лента со ставкой 14% и курсом юаня. Агент в этом запуске работает с `MOCK_LLM=1` и ключ не нужен.

Живые новости: у сервиса `parser` поставьте `PARSER_OFFLINE=0`. Живая модель: у сервиса `agent` поставьте `MOCK_LLM=0`, `LLM_BASE_URL=https://changellenge.up.railway.app/v1` и имена из списка кейса (`LLM_MODEL_LIGHT`, `LLM_MODEL_REASONING`, `LLM_MODEL_DEFAULT`). Ключ передайте через `LLM_API_KEY` в окружении процесса, не записывайте его в репозиторий. После этого снова `docker compose up --build`.

Имена моделей код сам не подставляет. Период отбора по умолчанию `2026-09-01` … `2026-10-31`.

Без Docker каждый модуль запускается из своего каталога по его README. Фронтенд соединяется со шлюзом переменной `ALFA_API_BASE=http://127.0.0.1:8080`. Пустое значение оставляет учебный набор фронтенда.

## Сценарий проверки

1. Откройте http://127.0.0.1:4173. В списке компаний выберите `C_LOAN`, роль — финансовый директор.
2. В ленте должно быть событие про ключевую ставку или курс, а не общая лента без компании. Переключитесь на `C_DEPOSIT`: набор и приоритет меняются, потому что у депозитного клиента нет кредита.
3. Откройте событие. На вкладке «Разбор» отдельно видны факты, фрагмент аналитики банка и интерпретация для компании. На вкладке «Источники и проверка» текст источника открывается по кнопке.
4. Задайте вопрос «Почему это важно именно этой компании?». Ответ ссылается на источники события. Это не заранее зашитый текст учебного набора: `is_demo` у рабочего пространства равен `false`.
5. `GET http://127.0.0.1:8010/health` показывает число клиентов, кластеров и нечитаемых PDF. `GET http://127.0.0.1:8010/traces/{trace_id}` из ответа инсайта содержит план, вызовы инструментов и проверку.
6. Повторите шаги 1–4 для `C_IMPORT` и новости про юань: во внешнеэкономическом профиле связь сильнее, чем у компании без ВЭД.

Тесты без Docker:

```bash
cd agent && python -m pytest
cd parser && python -m pytest
cd dedup && python -m pytest
cd gateway && python -m pytest
cd frontend && node --test tests/app.test.cjs tests/model.test.cjs
```
