# Сторонние компоненты

Парсер не вызывает LLM и не считает эмбеддинги. Разбор RSS, Atom и HTML написан на стандартной библиотеке Python.

## Библиотеки

- Python 3.12
- fastapi, uvicorn — HTTP API
- pydantic — документ на выходе
- httpx — запрос ленты и полного текста
- pyyaml — список источников и словарь меток
- pytest — тесты, в рантайм-образ не входит

feedparser, BeautifulSoup, newspaper и модели извлечения сущностей не подключаются.

## Данные

`fixtures/` — короткие синтетические ленты и заметка банка для офлайн-запуска и тестов. Живые адреса РБК, Коммерсанта, ТАСС, Интерфакса и Банка России указаны в `config/feeds.yaml` и запрашиваются только при `PARSER_OFFLINE=0`. Ключи и выгрузки кейса в модуль не входят.
